# Baki Hisab Pro 2.0
APK-ready Android Studio project.

Included:
- Google Sheets-style table/card workflow
- Manual Save button + automatic local persistence
- Add, Edit and delete people
- Payment History with date/time
- Running paid and remaining totals
- Search
- CSV export/share
- Excel button (exports CSV-compatible spreadsheet data)
- Josef placeholder; no Tushar data
- Min Android 6.0 / API 23

Open the folder in Android Studio, sync Gradle, then Build > Build APK(s).
